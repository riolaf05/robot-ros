🔌 Collegamenti Arduino Nano → L298N Motor Driver

📌 Dettagli Connessioni:
  • ENA/ENB (PWM): Controllano la velocità dei motori (0-255)
  • IN1/IN2: Controllano la direzione del motore sinistro
  • IN3/IN4: Controllano la direzione del motore destro
  • GND: Ground comune (ESSENZIALE)
⚠️ Attenzione: Rimuovi il jumper del regolatore 5V sul L298N per evitare sovraccarichi!

📡 Collegamenti Arduino Nano → Encoder

📌 Importante Encoder:
  • Channel A: DEVE essere collegato ai pin interrupt (D2, D3)
  • Channel B: Usato per determinare la direzione di rotazione
  • VCC: Alimentazione 5V dall'Arduino
  • CPR: Configurare nel codice Arduino (default: 374)
⚠️ Attenzione: Verifica la polarità VCC/GND dell'encoder. Un collegamento errato può danneggiare l'encoder!

⚡ Sistema di Alimentazione

⚠️ IMPORTANTE - Sicurezza Alimentazione:
  • Ground Comune: TUTTI i GND devono essere collegati insieme
  • Polarità: Verifica 3 volte prima di alimentare
  • Step-Down: Impostare esattamente a 5.0V (±0.1V)
  • Cavi: Min 18AWG per motori, 20AWG per 5V
  • L298N Jumper: Rimuovere il jumper 5V regulator
📊 Consumo di Corrente Stimato:
  • Raspberry Pi 4: 2.5-3A @ 5V
  • Arduino Nano: 200mA @ 5V (via USB da Raspberry)
  • RPLIDAR: 400-500mA @ 5V (via USB da Raspberry)
  • Motori DC: 1-2A each @ 12V (peak 2-3A)
  • Encoder: 50mA each @ 5V
Totale: ~15W @ 5V + 24-36W @ 12V (peak)

💻 Raspberry Pi 4 - Collegamenti

📌 Mapping Porte:
  • /dev/ttyUSB0: Arduino Nano (comunicazione seriale a 57600 baud)
  • /dev/ttyUSB1: RPLIDAR (comunicazione seriale + alimentazione)
  • /dev/video0: Camera USB (v4l2_camera)
  • Power: 5V tramite USB-C o GPIO Pin 4 (con cautela)
⚠️ Note Importanti:
  • Le porte USB potrebbero cambiare ordine. Verifica con ls -l /dev/ttyUSB*
  • Arduino DEVE essere su /dev/ttyUSB0 (configurato in ros2_control.xacro)
  • Se le porte sono invertite, scambia i cavi USB o modifica la configurazione
  • Raspberry Pi 4 richiede almeno 3A @ 5V per funzionare stabilmente
